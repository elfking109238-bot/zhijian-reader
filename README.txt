纸间 1.0.1 · Windows 本地电子书阅读器

启动
双击「纸间.exe」。无需安装、无需登录，也不需要另外安装 Node.js。
程序需要与旁边的 DLL、resources、locales 等文件放在一起。移动时请复制整个文件夹。
请将文件夹放在有写入权限的位置，例如文档或其他个人文件夹。

开始阅读
点击「导入书籍」，或把书籍文件拖到窗口中。
支持 TXT、EPUB、无 DRM 的 MOBI；同时接入 AZW3 / KF8 解析。
书架空白时可以点击「先读三本原创示例」，体验三种真实格式。
导入会建立本地副本，保留你的原文件。重复的文件会自动跳过。

阅读功能
目录导航、左右翻页、上下滚动、宋体 / 黑体、字号和行距调整。
浅色 / 暖纸 / 深色三种页面外观；默认暖纸背景。
分页模式支持鼠标滚轮向下下一页、向上上一页。
一次连续滚动或触控板惯性只翻一页；稍停后再滚可继续，反向可回翻。
目录与设置面板仍正常滚动；Ctrl+滚轮不翻页。滚动模式保持连续滚动。
添加和移除书签、书签跳转、搜索书名和作者、最近阅读、专注模式。
阅读位置、外观、书签自动保存。关闭程序后，再次启动可恢复到上次阅读。
按 Esc 返回书架，会停止自动打开该本书；在书架仍可点击「继续阅读」。

快捷键
← / → 或 PageUp / PageDown：翻页
空格：下一页
F：专注模式
Esc：关闭面板 / 退出专注 / 返回书架
Ctrl K：在书架搜索

TXT 编码
自动识别 UTF-8、UTF-16 BOM；非 UTF-8 默认使用 GB18030（兼容常见 GBK）。
若显示乱码，在书籍右下角「⋯」菜单选择编码后阅读；支持手动选择 Big5。
无 BOM 的编码无法总是准确猜测，必要时手动选择。

隐私与备份
不联网、不上传书籍、不加载书内远程资源、不执行书内脚本。
数据保存在程序旁的「纸间数据」文件夹中，包括原始字节副本、索引、书签和进度。
备份、迁移时请连同这个文件夹一起复制。请勿只移动 exe。
「移出书架」会删除书库副本和该书阅读记录；原来导入的文件不变。

格式与限制
MOBI 使用 Foliate 的真实 MOBI 6 / PalmDOC / HUFF-CDIC / KF8 解析链路。
已实测 MOBI 6 未压缩和 PalmDOC 压缩中文文件。HUFF-CDIC、KF8 / AZW3 已接入，未做样本覆盖，不保证所有出版物变体。
不支持 DRM、KFX、PDF、扫描书、含交互脚本的内容。检测到 DRM 会提示，不进行解密。
单本最大 100 MB，TXT 最大 20 MB；EPUB 解压总量最大 128 MB，单条目最大 16 MB、8000 个条目、压缩比限制 200 倍。
MOBI 解压文字最大 64 MB。超限书籍会提示，请先拆分。
这是本地自用构建，未使用商业数字签名。
